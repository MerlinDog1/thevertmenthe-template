# ThevertMenthe-style Portfolio Template

A lightweight starter template inspired by the visual structure of https://thevertmenthe.dault-lafon.fr/

## Includes

- Intro loader with animated percentage
- Fullscreen canvas background (placeholder visual scene)
- Fullscreen menu overlay with image/video texture
- Search bar + filterable artwork list
- Contact / Instagram links
- Mobile-responsive layout

## Run

Just open `index.html` in a browser.

## Customize

- Edit text/content in `index.html`
- Tune UI in `style.css`
- Replace placeholder canvas logic with Three.js/WebGL in `script.js`
- Swap menu image/video assets with your own
